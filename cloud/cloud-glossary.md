
# Cloud Glossary

| Term | Meaning | Example or use |
|---|---|---|
| Cloud computing | Using computing services over the internet. | Accessing online storage. |
| Cloud storage | Saving files on remote internet-connected servers. | Storing files online. |
| Cloud server | A server hosted in a cloud environment. | Hosting a website. |
| Virtual machine | A software-based computer running an operating system. | Running Ubuntu in a virtual machine. |
| Bucket | A container for storing objects in cloud storage. | Storing website images. |
| Object storage | A way to store data as objects. | Storing documents and images. |
| Region | A geographical area where cloud resources are hosted. | Choosing a cloud location. |
| Availability zone | An isolated location within a cloud region. | Improving service reliability. |
