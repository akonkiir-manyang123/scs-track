# SCS1.4 — Git Ignore Rules

## What I learned

I learned how to use `.gitignore` to prevent private and local files from being tracked by Git.

## What I did

1. Opened my bio-page project.
2. Created and inspected the `.gitignore` file.
3. Added ignore rules for `.env`, `*.pem`, and `*.key` files.
4. Added ignore rules for `/ls` and `/ls.pub`.
5. Checked my Git commit history to confirm the ignore-rule commits.
6. Checked Git status and confirmed that the working tree was clean.

## What I learned

The `.gitignore` file helps prevent selected private and local files from being added to Git. It does not remove files that are already tracked.
